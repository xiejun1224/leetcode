# 438. 找到字符串中所有字母异位词

**难度**：中等 · **专题**：滑动窗口（定长）

## 我写这题的三个版本

| 版本 | 做法 | 复杂度 | 问题 |
|:---|:---|:---|:---|
| v1 暴力 | 每个起点都把整段重新数一遍 | O(n·m) | 能过，但面试会被问"能不能优化" |
| v2 滑动窗口 | 定长窗口 + `unordered_map` | O(n) | 边界忘了判 `right < s.size()`，s 比 p 短时越界 |
| v3 数组+count | `int[26]` + 计数器 | O(n) | 最终版 |

## 关键点

1. **窗口长度固定**为 `p.size()`，右进左出，不需要"扩到不满足再缩"那套变长逻辑
2. `count` 记录"当前窗口内达标（频次 ≤ 目标）的字符总数"
   - 进一个字符：`++hashs[c] <= hashp[c]` 时 `count++`
   - 出一个字符：`hashs[c]-- <= hashp[c]` 时 `count--`（**先比较，后递减**）
3. `count == p.size()` 即所有字符都达标，而窗口长度又恰好等于 p 的长度
   ⇒ 每个字符频次都等于目标频次

## 踩过的坑

- **越界**：内层扩窗必须同时判 `right < s.size()`。s 比 p 短时，只判窗口没满会让 `right` 冲出字符串末尾（ASan 实测：`heap-buffer-overflow`，`READ of size 1 ... 0 bytes to the right of 21-byte region`）。LeetCode 上"能过"是因为越界读到野内存恰好不值钱，纯属运气。
- **`--` 的位置**：`hashs[out-'a']-- <= hashp[out-'a']` 里的 `--` 是**后置**。判断的是"这个字符离开之前，是否曾贡献过 count"；写成前置递减，比较的就是减完的值，语义全错。
